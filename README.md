# Department of Justice RP

Η δημόσια πύλη στο [GitHub Pages](https://duclet123.github.io/DoJ/) και το Workspace προσωπικού χρησιμοποιούν Firebase Authentication και Cloud Firestore.

## Ενεργοποίηση Firebase

1. Δημιούργησε ξεχωριστό Firebase project για το DoJ, στο πλάνο Spark, και πρόσθεσε μια εφαρμογή Web. Από τις ρυθμίσεις της εφαρμογής αντέγραψε το δημόσιο Web SDK config σε μορφή JSON στο `docs/firebase-config.json`. Χρησιμοποίησε τα πεδία `apiKey`, `authDomain`, `projectId` και `appId`. Το αρχείο δεν περιέχει κωδικούς ή service-account keys.
2. Ενεργοποίησε **Authentication → Sign-in method → Email/Password** και πρόσθεσε το `duclet123.github.io` στα **Authorized domains**.
3. Δημιούργησε τη βασική βάση Firestore σε production mode και εγκατέστησε τους κανόνες του repo. Χρησιμοποίησε το ID του **DoJ** project.

   ```sh
   npx firebase-tools login
   npx firebase-tools deploy --only firestore:rules --project DOJ_PROJECT_ID
   ```

   Εναλλακτικά, δημοσίευσε το περιεχόμενο του `firestore.rules` από την κονσόλα Firestore.
4. Δημιούργησε τους λογαριασμούς από το **Authentication → Users**. Για κάθε λογαριασμό πρόσθεσε έγγραφο `staff/{UID}` στο Firestore, με το UID του συγκεκριμένου λογαριασμού και τα πεδία `username` (όνομα εμφάνισης, string) και `role` (string, μία από τις τιμές `lawyer`, `prosecutor`, `judge`). Για την πρώτη υπόθεση χρειάζεται ένας λογαριασμός ανά ρόλο.
5. Αφού δημοσιευτεί το Firebase config μέσω GitHub Pages, δοκίμασε τη **Σύνδεση** με τους λογαριασμούς που δημιούργησες.

Η πύλη διαβάζει τον δημόσιο ποινικό κώδικα από τη συλλογή `penal`. Κάθε άρθρο έχει `code`, `title`, `category`, `description` και προαιρετικά `penalty` και `bail`. Όλα είναι πεδία κειμένου. Μέχρι να δηλωθεί Firebase config, η δημόσια σελίδα μπορεί να εμφανίζει τα άρθρα του `docs/penal-code.json`.

## Ροή υπόθεσης

1. Ο εισαγγελέας καταθέτει κατηγορητήριο, ορίζει δικηγόρο και δικαστή και καταχωρίζει περιγραφές αποδεικτικών.
2. Ο δικηγόρος υποβάλλει αιτήσεις. Οι προσωπικές σημειώσεις είναι προσβάσιμες μόνο στον συντάκτη και εξαιρούνται από την εκτύπωση.
3. Ο δικαστής ορίζει ακρόαση, εκδίδει απόφαση και καταθέτει ξεχωριστό κείμενο για τη δημόσια δημοσίευση.

Η δημόσια συλλογή `docket` περιέχει μόνο τα εγκεκριμένα πεδία των ακροάσεων και των δημοσιευμένων αποφάσεων. Τα στοιχεία σύνδεσης, οι φάκελοι και οι ιδιωτικές σημειώσεις δεν χρησιμοποιούνται από τη δημόσια πύλη.

## Παλαιότερη έκδοση Node

Ο κώδικας Node/SQLite και το παλιό Render blueprint παραμένουν διαθέσιμα για υπάρχουσες εγκαταστάσεις. Το GitHub Pages συνδέεται με Firebase. Αν υπάρχουν υποθέσεις στην παλιά βάση που πρέπει να μεταφερθούν, χρειάζεται ξεχωριστή εισαγωγή στο Firestore.
